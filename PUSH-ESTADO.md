# Avisos e separação — estado de 12/10/2026

A função push-notify versão 5 foi implantada no projeto ngidsolvxegpyrprlbex. Os preflights dos dois domínios oficiais responderam com a origem correspondente. A função exige JWT válido, verifica usuário e participação na conversa e filtra inscrições por subscription.app_id. O tópico das chamadas foi limitado a 32 caracteres compatíveis com Web Push.

As 17 inscrições antigas não têm app_id. Não foram atribuídas a aplicativos por suposição. É necessário abrir novamente os aplicativos corrigidos ou usar Perfil → Ativar e testar avisos neste aparelho para renovar o registro.

O código do IL Chats curto está preparado mas sua gravação no GitHub foi recusada com 403 Resource not accessible by integration. Falta habilitar IL-Chta/IL-Chta.github.io na instalação GitHub da conta IL-Chta. O Bate Papo curto foi atualizado.

A entrega em aparelhos físicos, inclusive depois de alternar aplicativos e bloquear a tela, ainda precisa ser testada. A separação das inscrições de push e das sessões locais não separa o banco de conversas/contatos: ambos ainda usam as mesmas tabelas. Essa etapa permanece pendente e não deve ser apresentada como concluída.
